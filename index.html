統計量化問卷與分析系統

Likert 量表 · 填答、存檔、後台分析

第一步：基本資料（匿名，僅供分組分析）

提醒：請勿填寫姓名、電話、電子郵件等可識別個人的資料。本問卷只記錄上面這些分組欄位與各題分數。

第二步：量表填答（5 點量表）

請依您的實際感受勾選，每題都要作答。分數越高表示越同意該敘述；構面分數為該構面各題的平均分數。

第三步：我的構面分數預覽

先看自己的各構面平均分數，確認無誤再送出。送出後會寫入 Google Sheets（或本機模式下存在填答者瀏覽器）。

管理後台

請輸入研究者設定的後台密碼（預設研究在 config.js，多研究在各研究題目檔的「後台密碼」）。這個密碼只是簡易門檻，不是真正的帳號驗證；請勿用它保護高度敏感資料，重要研究請把 repo 設為私人、並用匿名編號填答。

資料來源

點「查看」可看該筆的各題分數與構面分數。下載的 raw data 包含原始各題分數，可直接進 Excel、SPSS、JASP 或 R 再分析。

下載 Raw Data

勾選要跑的分析（預設全跑）。卡方、平均數檢定、變異數分析、共變異數分析、關聯分析、線性迴歸皆由 assets/stats.js 計算；顯著水準 α=.05。報告格式為論文第四章（表4-節-序；平均數、標準差小數第 2 位；t、F、χ²、r、R² 小數第 3 位；p 值小數第 3 位；*p<.05）。

這裡顯示目前研究的架構（來自題目檔或 config.js）。要正式更換研究架構，請改題目檔或按「下載新的 config.js」，覆蓋 repo 裡的 config.js 後重新部署。

計算方法：構面分數為各題平均；信度為 Cronbach's α；卡方 χ²、獨立／成對 t 檢定（Welch 與 Student 並列）、單因子 ANOVA（η²、ω²、Bonferroni 事後比較）、ANCOVA（先檢定斜率同質性，再報調整後平均數）、Pearson／Spearman 相關、OLS 線性迴歸（R²、VIF、Durbin-Watson）。α=.05；平均數、標準差小數第 2 位，t、F、χ²、r、R² 小數第 3 位，p 值小數第 3 位，判定以未四捨五入值計算。
